# UX Review — Collapsed research steps

## Review status

Approved by explicit user direction on 2026-08-08.

## Default state

Each step shows one row: step number, specific user-facing tool-execution title, and a disclosure chevron. No rationale, input, output, internal tool name, status badge, or actions are visible until expansion.

## Expanded state

Expansion reveals the current detailed presentation unchanged in meaning, including status, technical tool name, rationale, checked input, returned result, and actions.

## Accessibility

Use native `summary` keyboard behavior, a visible focus state, localized expand/collapse accessible text, and a chevron that reflects open state.
