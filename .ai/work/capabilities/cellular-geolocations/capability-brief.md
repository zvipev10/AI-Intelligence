# Cellular geolocations

User requests a new layer with IMEI, SIM and location, plus IMEIs in Cellular Calls. Implement Syria catalog and shared presentation/search support. Default: empty new layer, no invented data. Calls already have side_a_imei and side_b_imei; expose both in tables, preserving endpoint identity. Location uses existing location_id catalog. Keep string identifiers and existing record IDs/timestamps.
