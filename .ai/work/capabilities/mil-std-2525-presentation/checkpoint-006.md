# Corrective Checkpoint 006 — Focused UAV marker

The row-level Show on map action previously created only a popup. It now adds a
focused marker and uses the record's MIL-STD UAV descriptor, including hostile
affiliation for mapped KFOR/NATO entities. Generic records retain a standard
focused point marker. Release assets are `app.js?v=176`, `styles.css?v=146`,
and `deployment/SHA256SUMS-v179.txt`.
