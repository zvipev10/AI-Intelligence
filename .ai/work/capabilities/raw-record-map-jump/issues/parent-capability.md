# [Capability] Raw record to map jump

## Capability

Allow analysts to move from a raw event row directly to its spatial context.

## Current phase

Capability initiation

## Overall status

Pending product/user review

## Operational status

See `.ai/work/capabilities/raw-record-map-jump/status.md`.

## User problem

Raw result rows are disconnected from their map representation, forcing manual map navigation and location matching.

## MVP scope

Add a bilingual, accessible map action to raw event rows that activates the map, centers on the record location, and opens an event-specific popup.

## Acceptance criteria

- [ ] Raw rows with coordinates expose the action.
- [ ] The map centers on the correct location.
- [ ] The popup identifies the exact record.
- [ ] Table filters and sorting continue to work.
- [ ] Both locales and keyboard access are validated.
