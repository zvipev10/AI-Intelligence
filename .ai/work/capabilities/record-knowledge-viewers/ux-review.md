# UX Review

## Status
Approved for planning under the user's explicit delegation on 2026-09-09.

Use a focused modal dialog so the map, grid, filters, and conversation remain in place. The header shows object type, title, and canonical ID. Records prioritize source content, then metadata; organizations prioritize canonical identity, aliases, counts, and leading locations/sources.

Rows use a clear open-details button rather than making every cell interactive. A map marker opens details only when it represents one supported object. Assistant messages expose explicit record or organization identifiers as compact open buttons. The dialog supports Escape, backdrop/close controls, focus restoration, RTL/LTR, scroll containment, and stops media on close. Loading is unnecessary for client-resident objects; missing, unsupported, and failed media states are explicit.

Recommendation: continue.
