# UX Review

## Status

Approved from explicit user input.

## Accepted behavior

- Duplicate recordings are allowed.
- Both workstream messages use the same Save recording states as existing
  recordable messages.
- Listing and replay follow existing recording conventions; no special badge or
  workstream-only replay-action behavior is added.
- Replayed workstream content is read-only even where the original live card had
  mutation actions.

## Accessibility

Reuse existing button labels, disabled states, progress copy, and focus behavior.
