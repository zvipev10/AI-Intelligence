# [Capability] Investigation welcome page

## Capability

Investigation-oriented welcome page for the Serbia/North Kosovo workspace.

## Current phase

Phase 1 — capability initiation

## Overall status

Pending review

## Operational status

See `.ai/work/capabilities/welcome-page/status.md`.

## User problem

Users enter directly into an investigation and lack an overview for resuming work, managing participants, and discovering similar investigations.

## MVP scope

Add an initial welcome view with app/health/language header, one real existing-investigation ribbon, mocked secondary metadata, and a separate mocked similar-investigations section. Clicking the real ribbon reveals the existing workspace in the same document. Do not add a new-investigation action.

## Acceptance criteria

- [ ] The welcome page is the initial view.
- [ ] The real investigation and existing team are shown.
- [ ] Investigation-specific attention, invitations, activity, progress, and milestone content stays inside its ribbon.
- [ ] The ribbon opens the existing workspace in place.
- [ ] Nested participant actions do not trigger navigation.
- [ ] Similar investigations use clearly mocked data and actions.
- [ ] Existing investigation behavior passes regression checks.
