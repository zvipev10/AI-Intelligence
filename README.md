# AI Intelligence

This repository contains the AI Intelligence proof-of-concept work, with the active focus on the Serbia/North Kosovo investigation orchestrator.

The active application is a Hebrew analyst workspace backed by Hermes and MCP tools over the 14,800-record V2.1 synthetic intelligence dataset. It supports additive map/timeline/table result layers, explicit investigation memory, a compact `מכלול` team interaction model, and a specialized Moshe target-officer agent with isolated routing, mission continuity, and evidence-backed attack-target presentation.

- `PROJECT_HANDOFF.md` for the current project state, deployment notes, and continuation guidance.
- `llm_investigation_orchestrator_serbia_poc/README.md` for the active Serbia POC architecture, runtime configuration, MCP tools, semantic retrieval, saved questions, and verification commands.
- `.ai/work/capabilities/moshe-attack-targets/status.md` and `handoff-summary.md` for the latest specialized-agent release state and residual risks.
- `.ai/work/capabilities/michlol-team-management/status.md` for the current team-member interaction model and its review status.
